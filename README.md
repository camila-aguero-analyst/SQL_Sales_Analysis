# Sales Analysis Using SQL

## Overview

This project explores customer purchasing behavior using the **AdventureWorksDW2019** database through SQL-based exploratory analysis. The objective was to identify trends across customer demographics, product categories, and geographic regions to support data-driven business decisions.

The project demonstrates data exploration, aggregation, customer segmentation, and business analysis using SQL.

---

## 🛠️ Tools Used

* SQL Server
* AdventureWorksDW2019
* T-SQL
* GitHub

---

## SQL Workflow

| File                                    | Description                                                                      |
| --------------------------------------- | -------------------------------------------------------------------------------- |
| **01_monthly_sales_analysis.sql**       | Analyzes monthly sales trends for 2012 by extracting and formatting order dates. |
| **02_product_sales_by_subcategory.sql** | Identifies top-performing product subcategories using joins and aggregation.     |
| **03_sales_by_children_status.sql**     | Compares bike purchases between customers with children and those without.       |
| **04_sales_by_country.sql**             | Evaluates sales performance across geographic regions.                           |
| **05_sales_by_commute_distance.sql**    | Explores customer commute distance and its relationship to bike purchases.       |
| **06_sales_by_age_group.sql**           | Segments customers into age groups to analyze demographic purchasing patterns.   |

---

## Business Questions

* Which product categories generate the most sales?
* How do purchasing patterns differ across customer demographics?
* Which countries contribute the highest sales volume?
* Does commute distance influence bike purchasing behavior?
* Which age groups represent the largest customer segments?

---

## Key Skills Demonstrated

* SQL Joins
* Common Table Expressions (CTEs)
* Data Aggregation

* Date Manipulation

## Key Insights

* Sales trends reveal seasonal purchasing patterns throughout the year.
* Bike purchases vary based on customer family status and commute distance.
* Certain product subcategories consistently outperform others.
* Customer demographics provide valuable opportunities for targeted marketing strategies.
